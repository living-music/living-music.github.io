# Changelog

All notable user-visible changes to Living Music are recorded here.

## Unreleased

- Separated Favorites from per-song Library membership with distinct heart and add/check controls.
- Added Favorites above Recently Added in Library navigation.
- Limited partial albums opened from Library to their individually added songs.

- Moved Recently Added, Albums, Songs, and Music Videos into the Library sidebar and added a compact mobile switcher.
- Grouped saved songs by album in Recently Added and Albums.
- Added album saving and device-local add dates for saved songs and albums.

## 0.1.0 — 2026-09-07

- Added the dark-first responsive application shell and GitHub Pages deployment.
- Connected revisioned catalog browsing and lazy collection loading.
- Added continuous playback, Now Playing, alternate recordings, repeat, and editable Up Next.
- Added global search, on-device favorites, Library, and validated listening-state restoration.
- Added lock-screen and hardware controls through Media Session, accessibility polish, PWA metadata, and release documentation.
